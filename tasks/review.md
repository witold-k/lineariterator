This is a Rust project providing low-level iterators for strided traversal and fixed-width windows.

- Read all Rust source files and review them for correctness, soundness, clarity, and unnecessary complexity.
- Pay particular attention to unsafe code, pointer arithmetic, aliasing, lifetimes, and iterator contracts.
- Keep the implementation small and dependency-free.
- Run `just build` after changes and fix any resulting build, test, doctest, or Clippy failures.
